# Spotiyfy-Widget-

1. Dosyayı indir: spotify-card.plasmoid

Şifreni yazarken ekranda görünmez, normal. Onay isterse Enter bas.

2. Dolphin’de indirdiğin dosyanın bulunduğu klasörü aç. Boş alana sağ tık → Burada Terminal Aç. Ardından:

kpackagetool6 --type Plasma/Applet --install spotify-card.plasmoid

3. Widget’ı ekle:

Masaüstüne sağ tık → Düzenleme Moduna Gir → Widget/Gereç Ekle → Spotify Card ara → masaüstüne sürükle.

4. Spotify’ı açıp bir şarkı başlat. Kapak ve şarkı bilgileri gelmeli.

Tasarımı değiştirmek için widget’a sağ tık → Spotify Card Ayarları → Görünüm. Buradan yuvarlak, şeffaf veya 8-bit seçebilirsin.
